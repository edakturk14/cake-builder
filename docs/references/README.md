# Cake artwork references

Keep the angle, stand, lighting, and cake placement consistent between edits. These contact sheets are art direction for building reusable cake pieces.

| Sheet | Reading order |
| --- | --- |
| [Chocolate cake progression](chocolate-cake-progression.webp) | One-layer chocolate, two layers with a pink seam, princess topper, then Eda in icing. |
| [Flavors and candles](flavors-and-candles.webp) | Strawberry cheesecake, vanilla with a 40 candle, red velvet with raspberries and plain candles, then lemon with a 21 candle. |
| [Themed cakes](themed-cakes.webp) | Mushroom and coin motifs for Mario, racing car and checkered flag for Formula One, Spain football, tennis, chip and jacket motifs for the Jensen Huang request, then New Year’s. |

The [build brief](../build-brief.md) defines the actual layer counts, prices, and supported edits. Use the sheets for styling and placement. Keep the inscription editable and attach toppings to the same cake state the builder saves to the basket.
